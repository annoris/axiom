## 🔑 How to Unlock Full Access

Star [`annoris/axiom`](https://github.com/annoris/axiom) and complete **any one** of the following paths:

### Option 1 — Submit a Valuable Pull Request on `annoris/axiom`

- Propose a new battle-tested skill blueprint (problem framing, failure mode solved, and workflow steps).
- Add architecture diagrams, agent workflow playbooks, or real-world `GLOSSARY.md` / ADR case studies to `ARCHITECTURE.md` or `README.md`.
- Contribute complete, high-craft translations of the documentation.

### Option 2 — Open a High-Signal Technical Issue
Open a detailed Issue in [`https://github.com/annoris/axiom/issues`](https://github.com/annoris/axiom/issues):
- Real-world AI coding agent failure modes that deserve a dedicated AXIOM skill.
- UX, accessibility, or performance audits of the Live Explorer (`https://annoris.github.io/axiom/`).

### Option 3 — Direct Collaboration or Sponsorship
Want to collaborate with **AXIOM® Engineering** or sponsor the catalog? Reach out with your GitHub handle:
- **Email:** `hello@axiom.dev`
- **Subject:** `[AXIOM Full Access] Collaboration — @your-handle`

## 📋 Pull Request Steps

1. **Fork** [`annoris/axiom`](https://github.com/annoris/axiom).
2. **Create a branch**:
   ```bash
   git checkout -b docs/propose-new-skill
   ```
3. **Commit clean Markdown improvements** and open a **Pull Request** explaining the value of your contribution.
4. **Review &amp; Unlock**: Once your PR is merged or approved, you will receive access instructions for the complete **106-skill pack + Next.js 15 source code** directly on GitHub.
